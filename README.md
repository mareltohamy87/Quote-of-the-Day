A simple and clean Quote of the Day web application that displays a random inspirational quote each time the user clicks a button.
This project focuses on practicing JavaScript fundamentals, DOM manipulation, and basic UI structure.

🛠️ Technologies Used

HTML5 – Semantic and accessible structure

CSS3 – Styling and layout

Vanilla JavaScript (ES6) – Logic, events, and DOM manipulation

✨ Features

Displays a random quote on each button click

Clean and minimal UI

Quotes include both text and author

Uses JavaScript array and Math.random() for randomness

Lightweight and fast (no libraries or frameworks)

🧠 What I Practiced in This Project

Working with JavaScript arrays

Generating random values

DOM selection and manipulation

Event handling using addEventListener

Updating HTML dynamically using innerHTML
